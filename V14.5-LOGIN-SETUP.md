# v14.5 Login Security Setup

## 1. Google reCAPTCHA
Create a reCAPTCHA v2 Checkbox site in Google reCAPTCHA Admin.

Add these domains:
- construction-ai-seven.vercel.app
- your future custom domain, if any

You will receive:
- Site key
- Secret key

## 2. Front-end Site Key
Open `config.js` and set:

window.RECAPTCHA_SITE_KEY = "YOUR_RECAPTCHA_SITE_KEY";

The site key is public and may exist in client-side code.

## 3. Vercel Secret Key
In Vercel:
Project -> Settings -> Environment Variables

Add:
- Key: RECAPTCHA_SECRET_KEY
- Value: your Google reCAPTCHA secret key
- Environment: Production (and Preview if needed)

Never put the secret key in `config.js` or GitHub.

## 4. Redeploy
Redeploy the latest production deployment after adding the environment variable.

## Remember Me
The browser stores only the email address when Remember Me is checked.
The password is never written to localStorage.
Supabase continues to manage the authenticated session.
